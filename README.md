# Care Construction

A Flutter app for managing construction work offline — projects, labour, purchases, attendance, accounts and PDF reports.

Built by Muhammad Abdullah Rao.

## Features

- Projects — track construction projects, costs and progress
- Labour — manage workers and attendance
- Purchases — record materials and expenses
- Accounts & Reports — dashboard with charts and PDF reports
- Offline-first — local SQLite storage (`sqflite`), no internet needed

## Tech

- Flutter 3.13 / Dart
- Provider for state management
- `sqflite` + `sqflite_common_ffi` for local storage
- `fl_chart` for charts
- `pdf` + `printing` for PDF reports
- `intl`, `uuid`, `path_provider`

## Screens

- Dashboard
- Projects
- Labour

- Accounts & Reports
